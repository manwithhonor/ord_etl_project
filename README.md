# LiveDune -> Yandex ORD ETL
ETL-проект для ежемесячной передачи статистики по саморекламе.

## Как работает
### Скачиваем данные из LiveDune
Ссылка на сайт: https://pro.livedune.com/.  
Ссылка на АПИ:: https://api.livedune.com/docs/index.html.  
Ставим параметры **{"date_from": "2026-01-01", "date_to": сегодня}** и качаем данные для аккаунтов  
**"ВК": 3453313  
"МАХ": 3369918  
"Телеграм": 3050607.**

### Скачиваем данные из гугл таблицы
Берем [гугл таблицу](https://docs.google.com/spreadsheets/d/1YRn7y_pTmBcj9YGCXSPX1SnQRulvFgR59PKn8NB6yMw/edit) и 
скачиваем страницу auto_table.

### Обрабатываем данные
ОБъединяем таблицы из гугла и Лайвдюн. Если данные уникальны, обрабатываем так: смотрим разницу по просмотрам с 
суммарным столбцом, записываем как столбец за текущий месяц.
Если у каких-то постов повтоярется платформа и айди кретива, но отличается ссылка на пост, то просмотры за такие посты 
суммируем, в столбец с месяцем (например imps_09_26) для всех дублей будет записана одна и та же информация,
а в суммарном столбце imps_total записываем уникальные значения для каждого поста.  
Да, это запутанно, но что поделать.

### Заливаем данные в яндекс
Ссылка на сайт: http://ord.yandex.ru.  
Ссылка на АПИ: https://ord.yandex.net/api/docs#/.  
Данные при заливке формируются так:  
- Креатив (токен): берется из гугл таблицы
- Тип РК: всегда Иное
- Показы (факт): берутся из лайвдюн
- Показы (акт): равно "Показы (факт)"
- Начало показа (факт): либо дата публикации креатива, если в текущем отчетном месяце публиковали, либо первое число, если в предыдущие месяцы публиковали
- Начало показа (акт): равно Начало показа (факт)
- Конец показа (факт): обычно конец отчетного месяца
- Конец показа (акт): равно Конец показа (факт)
- Сумма без учёта НДС, ₽: всегда ноль, т.к. это самореклама
- Сумма с учётом НДС, ₽: всегда ноль, т.к. это самореклама
- Ставка НДС (в процентах): всегда ноль, т.к. это самореклама
- Сумма НДС, ₽: всегда ноль, т.к. это самореклама
- Стоимость единицы оказания услуг с учётом НДС, ₽: всегда ноль, т.к. это самореклама
